# NRMUSIC

Modern minimal Korean music website, ready for GitHub Pages.

## Deploy
Upload all files to a GitHub repository, then go to Settings → Pages → Deploy from branch → select `main` and `/root`.

## Notes
- Responsive mobile/tablet/desktop layout.
- No build step required.
- Images use stable Unsplash URLs and JavaScript fallback handling.
- WhatsApp floating button opens `https://wa.me/6282260786076?text=Klik%20For%20Join`.
- Demo player is a visual UI preview; it does not stream copyrighted audio.
